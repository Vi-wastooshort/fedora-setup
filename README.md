# fedora-setup
An automation script to install necessary packages and configure a Fedora Linux system for convenience, privacy, and security. This script was made to help me learn Python.

## Planned features:
- Install RPM Fusion
- Switch to Flathub
- Install codecs through ffmpeg
- Install NVIDIA GPU drivers, if applicable
- Install and apply firmware updates
- Setup auto updates through dnf
- Install and setup Btrfs-assistant and Snapper
- If on GNOME, install gnome-tweaks and Extension Manager
